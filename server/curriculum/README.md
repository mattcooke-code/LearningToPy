# Curriculum

Course content organised by module. Each module folder contains:

- `*.md` files — Lesson content in Markdown
- `L*_Exercise.json` — Coding exercise definitions (starter code, test cases, hints)
- `L*_Quiz.json` — Quiz question definitions
- `images/` — Badge icons and lesson images

## Module numbering

- M0: Tutorial (excluded from level/stats calculations)
- M1–M20: Core curriculum

## Lesson file naming

- `L1_Variables.md` — Lesson 1 content
- `L2_Exercise.json` — Coding exercise for lesson 2
- `L3_Quiz.json` — Quiz for lesson 3

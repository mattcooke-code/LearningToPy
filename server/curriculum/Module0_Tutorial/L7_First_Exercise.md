# Your First Python Program 🎉

Time to practice what you've learned! This simple exercise helps you:

- Edit code in the editor
- Run a Python program
- Submit for XP rewards

## The Program

You'll work with this simple program:

```python
name = "Python Learner"
print(f"Hello, {name}!")
```

## Your Task

Change `"Python Learner"` to your actual name or nickname.

That's it! Just one small change.

## Step-by-Step

1. Find this line in the code:

```python
name = "Python Learner"
```

2. Change it to your name:

```python
name = "Alex"  # Your name here!
```

3. Run the code (click **Run Code** button)

You should see: `Hello, Alex!`

4. Submit for XP! (click **Submit Code** button)

## Example

Before:

```python
name = "Python Learner"
print(f"Hello, {name}!")
```

Output: `Hello, Python Learner!`

After:

```python
name = "Alex"
print(f"Hello, {name}!")
```

Output: `Hello, Alex!`

## Ready?

1. Change the name

2. Click **Run Code** to test

3. Click **Submit Code** to earn XP!

Simple as that! 🎉

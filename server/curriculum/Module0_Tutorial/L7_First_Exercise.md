# Your First Python Program 🎉

Time to practice what you've learned! This simple exercise helps you:

- Edit code in the editor
- Run a Python program
- Submit for XP rewards

## The Program

You'll work with this simple program:

```python
name = "Python Learner"
print(f"Hello, {name}!")
```

## Your Task

Change `"Python Learner"` to your actual name or nickname.

That's it! Just one small change.

## Step-by-Step

**Step 1:** Find this line in the code:

```python
name = "Python Learner"
```

**Step 2:** Change it to your name:

```python
name = "Dave"  # Your name here!
```

**Step 3:** Run the code (click **Run Code** button)

You should see: `Hello, Dave!`

**Step 4:** Submit for XP! (click **Submit Code** button)

## Example

Before:

```python
name = "Python Learner"
print(f"Hello, {name}!")
```

Output: `Hello, Python Learner!`

After:

```python
name = "Dave"
print(f"Hello, {name}!")
```

Output: `Hello, Dave!`

## Ready?

1. Change the name
2. Click **Run Code** to test
3. Click **Submit Code** to earn XP!

Simple as that! 🎉

# Keyboard Shortcuts ⌨️⚡

Learn to code faster and navigate more efficiently with these essential keyboard shortcuts. Mastering these will make you a more productive programmer!

## Why Use Shortcuts?

- **Speed**: Execute actions without reaching for the mouse
- **Flow**: Maintain coding focus and rhythm
- **Efficiency**: Complete tasks in fewer keystrokes
- **Professional**: Developers use shortcuts daily

## Editor Shortcuts

### Basic Editing

| Shortcut                   | Action             | Example Use                         |
| -------------------------- | ------------------ | ----------------------------------- |
| `Ctrl+Enter` / `Cmd+Enter` | **Run code**       | Test your program quickly           |
| `Tab`                      | **Indent line**    | Python requires 4-space indentation |
| `Shift+Tab`                | **Unindent line**  | Fix over-indented code              |
| `Ctrl+/` / `Cmd+/`         | **Toggle comment** | Comment/uncomment selected lines    |
| `Ctrl+Z` / `Cmd+Z`         | **Undo**           | Oops! Go back one step              |
| `Ctrl+Y` / `Cmd+Y`         | **Redo**           | Restore what you undid              |
| `Ctrl+D` / `Cmd+D`         | **Duplicate line** | Copy current line below             |
| `Ctrl+X` / `Cmd+X`         | **Cut line**       | Remove line to clipboard            |
| `Ctrl+C` / `Cmd+C`         | **Copy line**      | Copy without selection              |
| `Ctrl+V` / `Cmd+V`         | **Paste**          | Insert clipboard content            |

### Navigation & Selection

| Shortcut              | Action             | Example Use                |
| --------------------- | ------------------ | -------------------------- |
| `Home`                | **Line start**     | Jump to beginning of line  |
| `End`                 | **Line end**       | Jump to end of line        |
| `Ctrl+Home` / `Cmd+↑` | **Document start** | Top of file                |
| `Ctrl+End` / `Cmd+↓`  | **Document end**   | Bottom of file             |
| `Ctrl+→` / `Alt+→`    | **Next word**      | Skip to next word          |
| `Ctrl+←` / `Alt+←`    | **Previous word**  | Back to previous word      |
| `Shift+Arrow keys`    | **Select text**    | Highlight while navigating |
| `Ctrl+A` / `Cmd+A`    | **Select all**     | Highlight entire document  |

### Multiple Cursors (Power Feature!)

```python
# Place multiple cursors with Ctrl+Click (Cmd+Click on Mac)
item1 = "apple"
item2 = "banana"   # ← Click here with Ctrl held
item3 = "cherry"   # ← Then click here
# Now type to edit all three lines at once!
```

| Shortcut                       | Action                         |
| ------------------------------ | ------------------------------ |
| `Ctrl+Click` / `Cmd+Click`     | Add cursor at clicked position |
| `Ctrl+Alt+↑/↓ `/ `Cmd+Alt+↑/↓` | Add cursor above/below         |
| `Esc`                          | Exit multi-cursor mode         |

## Terminal Shortcuts

| Shortcut           | Action          | Example Use                     |
| ------------------ | --------------- | ------------------------------- |
| `Enter`            | Execute command | Run typed Python code           |
| `↑ / ↓`            | Command history | Cycle through previous commands |
| `Ctrl+L` / `Cmd+L` | Clear terminal  | Start with clean output         |
| `Tab`              | Auto-complete   | Complete file/command names     |
| `Ctrl+C` / `Cmd+C` | Interrupt       | Stop running program            |
| `Ctrl+D` / `Cmd+D` | Exit            | Close Python interactive mode   |

## Practice Exercises

Try these shortcut exercises in the editor:

**Exercise 1: Comment Toggle**

```python
# 1. Select all three lines below
# 2. Press Ctrl+/ (Cmd+/ on Mac) to comment/uncomment
print("Line 1")
print("Line 2")
print("Line 3")
```

**Exercise 2: Multi-line Edit**

```python
# 1. Hold Ctrl (Cmd) and click after each = sign
# 2. Type "orange" to change all values at once
fruit1 = "apple"
fruit2 = "banana"
fruit3 = "cherry"
```

**Exercise 3: Navigation**

```python
# Practice these in this code block:
# - Home/End to jump line ends
# - Ctrl+→ (Alt+→) to jump by words
# - Ctrl+Home/Ctrl+End for document bounds

def calculate_total(items):
    total = 0
    for item in items:
        total += item.price
    return total
```

## Common Shortcut Patterns

**The "Edit-Run" Loop (Most Common)**

1. Write code → `Tab` to indent

2. `Ctrl+S` to save (automatic on our platform)

3. `Ctrl+Enter` to run

4. See results, repeat!

### The "Debug" Flow

1. `Ctrl+Click` to add breakpoints (line numbers)

2. `Ctrl+Enter` to run

3. `Ctrl+L` to clear terminal between runs

4. `↑` to recall previous commands
